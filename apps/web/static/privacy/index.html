Okdam Songbook 개인정보처리방침

최종 업데이트: 2026-08-13 · 적용 범위: OCI에서 운영하는 Songbook 웹 서비스

1. 수집하는 정보

  • Google 계정 이메일
  • Google 계정 표시 이름
  • 로그인 세션 식별자와 만료 정보
  • 곡 등록 요청 본문 (제목, 아티스트, TJ 번호, 부를 사람, 추천 키, 메모 등)
  • 요청 시각과 ChangeLog (감사 로그)

2. 이용 목적

  • 허용 사용자 여부 확인 (allowlist 검증)
  • 곡 등록 및 중복 검사에 사용
  • 변경 이력 감사 (누가 언제 어떤 곡을 추가했는지)
  • 세션 만료 및 부정 사용 탐지

3. 허용 사용자

서비스는 운영자가 등록한 Google 계정만 사용할 수 있다. 등록되지 않은 계정은 접근이 거부된다.

허용 계정과 역할은 보호된 서버 설정에서 관리하며, 보호된 요청마다 현재 권한을 다시 확인한다.

4. 보관 기간 및 위치

  • 세션: 보안 HTTP 전용 쿠키와 서버 세션 저장소에서 정책에 따라 보관
  • 곡·공연 데이터: OCI SQLite 데이터베이스에 저장, 운영자가 삭제할 때까지 유지
  • 변경 이력: 같은 데이터베이스의 감사 기록으로 보관

5. 제3자 공유

수집한 정보를 판매하거나 광고 목적으로 공유하지 않는다. 서비스 운영에 필요한 호스팅·로그인 제공자와의 처리는 필요한 범위에서만 이뤄진다.

6. 삭제 요청

등록된 곡, ChangeLog, 세션 데이터의 삭제를 요청하려면 아래 연락처로 이메일을 보내주면, 운영자가 합리적인 기간(통상 14일) 이내에 처리한다.

7. 연락처

개인정보 관련 문의: 운영자가 별도로 안내한 비공개 연락처.

8. 정책 변경

이 정책은 필요 시 사전 공지 후 변경될 수 있다. 변경 시 이 페이지의 "최종 업데이트" 날짜를 갱신한다.
